# 2026-11-04 — Costa Bits: a new name and song; the loose songs in the player

On `ccr-5ceb056d-y3evh6`.

## User request

- Use "Victory in the Rearview" as Costa del Sol's song.
- Keep the songs no track uses, and list them in a music player in Options,
  saying which are a circuit's and which are loose (the engine's
  `RECORD/2026-11-04.music-player.WIP.md`).
- Call the track "Costa Bits" instead of "Costa del Sol".

## Implementation

- **The song:** `assets/music/victory_in_the_rearview.mp3` (176.5 s,
  −13.2 LUFS above 500 Hz, measured as `music.ron` says). It is the
  circuit's song and in `pack.txt` in place of `sunset_victory_lap.mp3`.
- **The loose songs:** `music.ron`'s new `loose` names five:
  - Sunset Victory Lap, the song Costa Bits had;
  - Crown of the Track;
  - Last Lap of the Quest;
  - Orange Asphalt;
  - Pursuit at the High Pass.

  They are measured the same way and listed in `pack.txt`, so a release
  carries them (about 21 MB more, on the web too). `the_iron_paddock.mp3`
  is the same file as `moon_base.mp3`, so it is left out. Moon Base's song
  is titled "The Iron Paddock" instead (`title` in `moon_base.ron`).
- **The name:** "Costa Bits" (`name`, `name_en`). Files renamed:
  - `assets/circuits/costa_del_sol.ron` to `costa_bits.ron` (in
    `circuits.ron` and `pack.txt`);
  - `docs/costa-del-sol-props.md` to `costa-bits-props.md`;
  - `web/images/track-costa-del-sol.jpg` to `track-costa-bits.jpg`.

  `formerly: ["Costa del Sol"]` moves the records saved under the old name.
  README, ROADMAP, `docs/tracks.md`, the props' list and the web follow;
  the completed records keep the old name, as written.
- `src/game/checks.rs`: `the_music_player_lists_every_song_once_and_plays_it`.
- Docs: `docs/gameplay.md` (Options > Sound) and `docs/architecture.md`.
- `ROADMAP.md`: the music player among what came in alongside.

## Verification

- `tools/with_engine.sh ../motorust-engine cargo test` (the engine's branch
  with the player): 235 passed, 0 failed, 1 ignored.
  - A first run failed everywhere: RON wants `title: Some("…")`, not a bare

  - Then `the_music_stays_well_under_the_player_s_engine` failed for
