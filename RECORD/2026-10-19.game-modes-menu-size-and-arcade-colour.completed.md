# The game modes' menu a little bigger; Arcade's orange darker

**Date:** 2026-10-19. **Branch:** `claude/sleepy-galileo-s35zhl`.

## User Request
- "Make Arcade's orange somewhat darker, so it has more contrast."
- "Make the game mode menu a little bigger, without making the type bigger."

## Implementation Details
- **Arcade's colour** (`modes::lit`): sRGB (0.9, 0.5, 0.0), was (0.98, 0.7, 0.0): its white lettering about 2.8 : 1 against it, was about 1.8 : 1 (relative luminance). Its badge on the later screens and in the pause menu takes it too.
- **The cards bigger, the type as it was** (`modes::GROW`, 1.15): the cards' row as wide as 1.15 times the start menu (`cards_width`, still never wider than 92 % of the window), their heights and gaps in proportion; the names' lettering worked out as on cards the start menu's size (its height and the room it fits in divided by `GROW`), and the descriptions' and the title's type as before (20, 15 and 44 px).
