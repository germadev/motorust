# CI: clippy asks for `as_chunks` in the world's textures and meshes

- **Date:** 2026-10-21
- **Branch:** `perf/tweaks`

## 1. User Request

- The CI failed at `cargo clippy --all-targets -- -D warnings` with the lint
  `clippy::chunks_exact_to_as_chunks`: six places in the world code split a
  slice into fixed chunks of three or four. The lint wants `as_chunks` /
  `as_chunks_mut` instead.

## 2. Implementation Details

Six call sites, all of them a straight swap that keeps the same behaviour (any
remainder is dropped, exactly as `chunks_exact` did):

- `src/world/lawn.rs:195` — `mean_of` now walks the pixels with
  `pixels.as_chunks::<4>().0`, each pixel an array of four bytes.
- `src/world/lawn.rs:652` — the wide lawn's red channel is taken with
  `data[..pixels * 4].as_chunks::<4>().0.iter().map(|p| p[0])`.
- `src/world/middle_earth.rs:636` — the arch's triangles are wound the other way
  with `indices.as_chunks_mut::<3>().0.iter_mut()`.
- `src/world/relief.rs:269` — the relief's lightness comes from
  `data[..width * height * 4].as_chunks::<4>().0.iter()`.
- `src/world/relief.rs:608` — the relief's tangent frames come from
  `corners.as_chunks::<3>().0`.
- `src/world/textures.rs:826` — the planks' gaps are cut with
  `data.as_chunks_mut::<4>().0.iter_mut().enumerate()`.

## 3. Verification & Testing

- `cargo clippy --all-targets -- -D warnings`: clean over the whole crate.
- `cargo fmt --check`: clean.
- `cargo test`: 626 passed, 0 failed, 2 ignored.
