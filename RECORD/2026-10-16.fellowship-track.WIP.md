### 3.2 Implementation Details
- **The art style**, one for every model so the track holds together, as a block after each prompt: *"Realistic fantasy film set style, hand-built weathered materials, muted natural colours, even lighting, no baked shadows. Single isolated object, no base, no ground, no text."* Each prompt carries its stretch's own materials and colours: the Shire's ochre plaster, red brick, weathered oak and faded paint; Bree's grey fieldstone, dark timber and cream plaster; the grey granite with moss and lichen of the ruins, the trolls and the Argonath; Rivendell's ivory stone, silver-grey wood and Art Nouveau curves; Moria's dark granite and angular edges; Lothlórien's silver bark and pale gold. ### 8.6 Tools for going on (`tools/fellowship_dev/`, development only)
- `probe_world.rs`: an ignored test that dumps the centre line (`line.tsv`: index, x, z, heading, road height, curvature, wall) and the ground every 4 m (`ground.bin`, x −500…2300, z −1000…1100: height and nearest-road distance as f32 pairs). To use it, add at the end of `src/world/mod.rs`: `#[cfg(test)] #[path = "<abs path>/probe_world.rs"] mod probe_world;`, fix the output paths inside it, and run `cargo test --release probe_dump -- --ignored --nocapture`.
- `capture.rs`: a screenshot plugin. Add to `src/main.rs`: `#[path = "<abs path>/capture.rs"] mod capture;` and, after the plugins, `if std::env::var("MOTORUST_SHOTS").is_ok() { app.add_plugins(capture::CapturePlugin); }`. It reads `MOTORUST_SHOTS` (a file of lines `name x y z tx ty tz`) and `MOTORUST_SHOTS_OUT` (a folder), waits 40 s for the world, then takes a shot every 22 frames. Run headless with Mesa lavapipe: `apt-get install -y libxkbcommon-x11-0 mesa-vulkan-drivers`, then `VK_ICD_FILENAMES=/usr/share/vulkan/icd.d/lvp_icd.json xvfb-run -a -s "-screen 0 1280x720x24" cargo run --release` with the two variables set (the track must be the selected one; see `shots.py` for how the shot lists are made).
