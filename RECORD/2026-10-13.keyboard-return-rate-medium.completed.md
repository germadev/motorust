# Keyboard and D-pad Return Rate: the Old Slow Becomes Medium

**Date:** 2026-10-13
**Branch:** `claude/loving-maxwell-vr7uub`

## 1. User Request
"Sobre el valor de retorno al soltar el teclado/cruceta, usaría el valor actual de lento como el valor medio" (for the return rate when the keyboard or D-pad is released, use the current slow value as the medium one).

## 2. Implementation Details
- `src/pause.rs`, `ReturnRate::factor`: medium (the default) is now 0.5, what slow used to be; slow keeps the same proportion to medium as before (two thirds: 1/3); fast stays the original 1.0. Measured with the steering model (`digital_steer_with_rates`, key held 0.5 s at a standstill): straight again 0.875 s after letting go with medium (was 0.7 s), 1.1 s with slow (was 0.875 s), 0.59 s with fast (unchanged).
- `docs/gameplay.md`: the return times and the levels of both rates.

## 3. Verification & Testing
- Existing tests on the order of the rates and on the fast and slow returns still hold.
- `cargo test`: 250 passed. `cargo fmt --check` clean, `cargo clippy --all-targets` no warnings.
