# Motorust Development Record: Split-Screen, WebAssembly & Speed Bay

- **Status:** Complete (merged into `main`).
- **Dates:** 10-11 October 2026.
- **Milestone:** Releases `v0.0.1` and `v0.0.2`.

---

## Chronology

### 38. Multi-Language and Fullscreen Toggle (`845f516`)

Requests:
- Support English and Spanish UI localization.
- Provide a dedicated fullscreen toggle row in options and welcome screens.

Done:
- Added `locale.rs` supporting English and Spanish text lookups.
- Added fullscreen checkbox in settings and welcome screen.

---

### 39. WebAssembly and Cloudflare Pages/R2 Deployment (`e1f7409`, `605a33b`, `f2ae257`, `7a90ab4`)

Requests:
- Deploy the game to the web using WebAssembly.
- Optimize asset and wasm delivery for browser play without bundle size limits.

Done:
- Implemented wasm32 build pipeline with `wasm-bindgen`.
- Offloaded the heavy `.wasm` binary to Cloudflare R2 storage bucket.
- Created Cloudflare Pages serverless function (`functions/`) to stream the binary with proper `application/wasm` MIME headers.
- Tagged release `v0.0.1`.

---

### 40. Local 2-Player Split-Screen Mode (`b0dd1e3`, `c6b19c8`, `e020a01`)

Requests:
- Allow two players on the same computer with horizontal split screen (top / bottom).
- Provide a lobby screen to choose controller vs keyboard and bike liveries.

Done:
- Implemented `Lobby` screen for local player slots (`LocalPlayer(0)` and `LocalPlayer(1)`).
- Configured Bevy dual camera viewports for top-and-bottom horizontal split screen.
- Resolved query conflicts between multiple bike input systems.
- Handled gamepads and keyboard bindings independently for both players.

---

### 41. Speed Bay Circuit Redesign (`a96d31d`, `tag: v0.0.2`)

Requests:
- Redesign the Speed Bay circuit layout to capture the PlayStation classic feel with seaside elevation changes and technical corners.

Done:
- Redesigned circuit centerline control points, elevation profile, and banking.
- Added inlet under bridge, scenic town spans, and seaside boulevard landmark details.
- Tagged release `v0.0.2`.

---

### 42. Cornering Grip Tuning & Desktop Downloads (`af125fe`, `c56e550`)

Requests:
- Equalize extra cornering grip across all speeds for better arcade handling.
- Add desktop download links to the web frontend and automated release assets.

Done:
- Tuned cornering physics in `bike/mod.rs` so leaning reward is consistent at both low and high speeds.
- Added macOS `.app` bundle, Windows `.zip`, and Linux executable releases in GitHub Actions workflow.
- Updated web frontend with direct download buttons for native desktop builds.
