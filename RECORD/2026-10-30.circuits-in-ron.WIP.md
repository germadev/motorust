# Circuits in RON (2026-10-30)

Step 1 of "The engine apart from the game" in `ROADMAP.md`: circuits as data, Bahía GP first.

## 1. Bahía GP in RON (2026-10-30)

### 1.1 User Request
> "Le damos caña al motor de .ron?" (shall we get going on the .ron engine?), and then "Seguimos?" (shall we go on?).

### 1.2 Implementation Details
- **`assets/circuits/bahia.ron`** (new): the whole of Bahía GP (names, descriptions, ambience, song, pace, layout and scenery) as it was in `src/circuits/bay.rs`, its comments kept. `bay.rs` keeps only the two functions the file names: `coast` and `mountains`.
- **`src/circuits/data.rs`** (new): reads a circuit's file into the same `Circuit` (`parse`, `load`). The layout and scenery types derive `Deserialize` where they stand (`src/track.rs`, `src/world/scenery.rs`), with `deserialize_with` readers from `data.rs`: lists read into a `Vec` and leaked to `&'static`, texts leaked, so the code using a circuit is unchanged; colours as their sRGB `(r, g, b)`; a `Span` as `Span(from, to)` or `Lap`; points as `(x, z)`; the terrain's functions by name (`Coast` through `CoastFile`, `terrain_function` in `src/circuits/mod.rs`); the song by its file's name (`music` in `mod.rs`, which builds the MP3 in). Every struct read is `deny_unknown_fields`; what a file leaves out of the scenery is empty or `None`. Not readable yet, and refused if written (`#[serde(skip)]`): terraces, bridges, dams, the pit, the mine, the desert, Japan, Middle-earth, space and the toy store. Serde ties types holding `&'static str` to input lasting as long, so a file is read from `&'static str` (built in with `include_str!`, or leaked once from the disk): `Scenery` says so in its bound.
- **`CIRCUITS`** is now a `LazyLock<[Circuit; 8]>` reading the files the first time it is wanted; the loops over `&CIRCUITS` became `CIRCUITS.iter()`. In a desktop development build the file is read from the disk if there (`CARGO_MANIFEST_DIR/assets/circuits/`), so a change shows with a restart and no compiling; release builds and the web carry it built in.
- **`tools/circuit_layout.py`** reads a circuit's RON file too (`control_points`, `elevation` and the massifs).
- **Docs:** `docs/tracks.md` (where tracks live, how to add one, "Circuits in RON"), `docs/architecture.md` (`src/circuits/`, `assets/circuits/`, the tool), `ROADMAP.md` (step 1 begun, and what is next).

### 1.3 Verification & Testing
- While moving it, a temporary test compared the Bahía read from the file with the old Rust `BAY` (from git) field by field (texts, ambience, song, layout, every list of the scenery, the coast and mountains at sample points): the same. Removed once it passed.
- New tests in `data.rs`: `every_circuit_file_reads`; `mistakes_are_told` (an unknown field, an unknown function and scenery a file cannot give yet are refused, naming what is wrong); `spans_and_colours`.
- `tools/circuit_layout.py assets/circuits/bahia.ron` gives the same lap as it did from `bay.rs` (1617.9 m, tightest bend 33.9 m at 846 m, steepest grade -11.2 % at 174 m, the start straight's crest).
- `cargo test`: 717 passed, 2 ignored (before the temporary test was removed). `cargo fmt --check` and `cargo clippy --all-targets -- -D warnings` clean. The web build (wasm32) was not built here (no target installed in this container).

## 2. Turbo Bay in RON (2026-10-30)

### 2.1 User Request
> "Ok, dale" (go ahead): the next circuit, Turbo Bay, as suggested.

### 2.2 Implementation Details
- **What a file can give now:** terraces, bridges (`BridgeStyle`) and dams (`Dam`, with its lake and river) derive `Deserialize` and are read (`Terrace::tilt`, `Bridge::fence` and `Dam::monument` may be left out). Still refused: the pit, the mine, the desert and the themed scenery (`mistakes_are_told` now tries `mine`).
- **`assets/circuits/turbo_bay.ron`** (new): the whole of Turbo Bay. Its long lists (control points, elevation, coast, massifs, the lake and the river) were converted from the Rust source by a scratch script, comments kept; the rest by hand. A file has no constants, so the stretches the Rust named (`SEAFRONT`, `CREST`, `GORGE.from + 20.0`, ...) are written out, and a comment at the file's top says where things are. `turbo_bay.rs` keeps only `mountains`, named `turbo_bay_mountains`; its song is named in `music`.
- **`tools/circuit_layout.py`** draws a file's coast (`Outline`) and its dam's lake and river.
- **Docs:** `docs/tracks.md` (the files, that they write numbers instead of constants, the layout example now in `loop_island.rs`), `docs/architecture.md`, `ROADMAP.md` (Loop Island next).

### 2.3 Verification & Testing
- A temporary test compared the Turbo Bay read from its file with the old Rust `TURBO_BAY` field by field (texts, ambience, the song's bytes, layout with its banking and narrows, coast, the mountains at sample points, and every list of the scenery, terraces, bridges and dam included): the same. Removed once it passed.
- `tools/circuit_layout.py` on `assets/circuits/turbo_bay.ron` and on the old `turbo_bay.rs`: the same lap (4344.2 m, tightest bend 29.6 m at 3332 m, steepest grade -11.8 % at 1594 m, the same three crests), and the plans drawn pixel for pixel identical.
- `cargo test`: 716 passed, 2 ignored. `cargo fmt --check` and `cargo clippy --all-targets -- -D warnings` clean.
