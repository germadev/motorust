## 1. User Request
The user tested the start screen and options menu and requested the following adjustments:
1. **Options Exit (B / ESC)**: Exiting options with B on gamepad or ESC on keyboard must close options properly and restore the previous screen.
2. **Options Tab Switching (L/R on Gamepad, TAB on Keyboard)**:
   - Gamepad: L (L1/L2) or R (R1/R2) to change sections/tabs.
   - Keyboard: TAB (and Shift+Tab to reverse) to change sections/tabs.

   - Make the start menu larger.
   - Instead of small icons, use colored background cards with a large helmet silhouette.
   - 1 player: colored card with a large single helmet silhouette.
   - 2 players: colored card with large double helmet silhouettes.
4. **Options Button Style**:
   - Colored background card with icon and text in the same matching color.
5. **Exit Game Button Style**:
   - Colored background in red with matching icon and text.
6. **PlayStation / DualSense Legend Buttons**:
   - Badges must be white (`badge_bg: Color::WHITE`) with face symbols in classic PlayStation 1 colors (Blue Cross, Red Circle, Pink Square, Green Triangle) and dark charcoal text for trigger/directional buttons.

   - SELECT should no longer open options directly ("SELECT ya no abre opciones"): options is accessed via the menu item, avoiding unintended trigger shortcuts.

## 2. Root Cause Analysis & Implementation Details

### 2.1 Options Modal Despawn & Exit Bug
- **Root Cause:** In Bevy ECS, `show_options_menu` was previously scheduled with `.run_if(options_menu.is_open)`. When `use_options_menu` set `options_menu.is_open = false` on B/ESC press, `show_options_menu` was skipped that frame, leaving `OptionsModal` permanently rendered on screen. Furthermore, when `show_options_menu` ran, it lacked an early return check after despawning `shown` entities, causing it to immediately re-spawn the modal.
- **Solution:** In [src/options.rs](file:///Users/joshua/dev/joshua/motorust/src/options.rs):
  - In `OptionsPlugin`, `show_options_menu` now runs unconditionally after `use_options_menu`.
  - At the start of `show_options_menu`:
    ```rust
    for entity in &shown {
        commands.entity(entity).despawn();
    }
    if !options_menu.is_open {
        return;
    }
    ```
  - ESC (`KeyCode::Escape`) and B (`GamepadButton::East`) immediately close the modal and cleanly despawn all UI nodes.
