# Retro Box Art and Web Style Overhaul

- **Date:** 2026-10-15
- **Task:** Overhaul the web landing page with retro game box aesthetics, screenshot presentation, uncluttered background, and animated watermark pattern.
- **Status:** Completed

## 1. User Request
The user expressed that the existing landing web page felt too simplistic ("la web es muy simplona, me gustaría algo con más estilo") and requested:
- Adding in-game captures styled like retro game boxes (e.g. 90s console / PC jewel case and big box art).
- Keeping an uncluttered, clean background ("background despejado").
- Adding an animated watermark-style pattern ("un patrón tipo marco de agua animado").

## 2. Implementation Details

### 2.1 3D Retro Box Art Presentation (`web/index.html`)
- Created an interactive 3D retro box art component inspired by late 90s arcade & motorcycle racing big boxes (such as *Moto Racer* 1997):
  - **Spine:** Deep textured charcoal edge with vertical embossed title `MOTORUST ARCADE` and product code `MR-1997`.
  - **Arcade Header:** Vintage console/arcade header with checkerboard racing flag trim and `BEVY 3D ARCADE EDITION` pill.
  - **Cover Showcase:** Crisp in-game capture (`web/images/track-turbo-bay.jpg`) with corner vignette, tech spec chips (`120 Hz Physics`, `8 Bikes & AI`), and retro title typography.
  - **Seals & Stamps:** Classic gold-dashed "ARCADE SEAL OF QUALITY" emblem with stars.
  - **Gloss & Specular Sheen:** Dynamic specular gradient layer (`.box-gloss`) that responds in real time to mouse tracking over the card.
  - **3D Perspective Tilt:** Interactive mouse move handler that calculates `rotateX` and `rotateY` angles (`perspective(1000px)`), producing a tactile 3D physical card feel.
  - **Interactive Screenshot Switcher:** Added retro track pill buttons beneath the box art (`Turbo Bay`, `Bahía GP`, `Loop Island`, `Menú`) allowing users to switch the showcased track screenshot seamlessly with crossfade animation.

### 2.2 Uncluttered Background & Animated Watermark Pattern (`web/index.html`)
- Set a deep, elegant dark palette (`#07090e` base with subtle ambient glows).
- Designed an animated repeating SVG watermark background layer (`.watermark-layer`):
  - Incorporates angled racing checkerboard flag bands, dashed apex circuit circles, and stylized `MOTORUST` outline wordmarks.
  - Rendered with low opacity (4.5%) and masked with a soft radial vignette so the screen remains clean, spacious, and uncluttered ("despejado").
  - Animated with seamless, GPU-accelerated diagonal drift via `@keyframes watermarkDrift (280px, 280px)`.

### 2.3 Web Landing Layout & Typography (`web/index.html`)
- Integrated modern Google Fonts: `Chakra Petch` (retro arcade speed headlines and badges) and `Outfit` (clean modern typography).
- Responsive two-column layout on desktop, smoothly collapsing into a centered single column on mobile devices.
- Refined the primary hero CTA button (`#start-btn`) with energetic orange rust gradient, ambient pulse glow, and download status feedback.
- Styled the desktop download cards (`#dl-win`, `#dl-linux`, `#dl-mac-arm`, `#dl-mac-intel`) with automatic system detection highlighting ("TU SISTEMA").
- Maintained all existing WebAssembly loading, Cache Storage, WebGL2 diagnostics, and AudioContext unlocking behavior.

### 2.4 Build System & Asset Delivery (`web/build.sh`, `web/images/`)
- Added screenshot assets to `web/images/`: `track-turbo-bay.jpg`, `track-bahia.jpg`, `track-loop-island.jpg`, `welcome.jpg`, `turbo-bay.jpg`.
- Updated `web/build.sh` to copy `web/images` to the distribution output directory (`$out/images`) during packaging.
