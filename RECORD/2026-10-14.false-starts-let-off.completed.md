## 2. False Starts

### 2.1 User Request
> "en el modo de semáforo sin bloqueo, añadir una opción para indicar el número de oportunidades de salida fallida, por defecto permitir dos fallos por circuito"

### 2.2 Implementation Details
- **`Settings::false_starts`** (`FALSE_STARTS` 0–3, `DEFAULT_FALSE_STARTS` 2): Options > Game "Salidas nulas permitidas" / "False starts let off", faint unless the start is "Lights, no hold"; reset with the section.
- **`jump_starts` (`src/race/lights.rs`):** a player moving off before the lights go out with false starts left is let off: the false start is counted (`Standing::false_starts`, one entry for each, per race: a new race, or a restart once started, clears it), `RecallToGrid` is written and the lights start again, `RECALL_PAUSE` (1.5 s) later than usual. Past them, disqualified as before. With 0, the first jump disqualifies.
- **`RecallToGrid` (`src/bike/mod.rs`):** `restart_race` takes it as the restart key: every bike back to its grid slot.
- **Held before the first light (`holds_now`):** with the bikes free, they are still held until the first light comes on, so a throttle still down after a recall does not jump the start again at once.
- **The notice (`src/race/hud.rs`):** back on the grid until the race starts, "¡SALIDA NULA!  1 de 2" / "FALSE START!  1 of 2" in gold.

### 2.3 Verification
- New tests: `the_first_false_starts_send_everybody_back_to_the_grid` (two recalls with the lights started again after the pause, then disqualified), `free_or_not_nobody_moves_before_the_first_light`, `back_on_the_grid_after_a_false_start_it_says_how_many`; the disqualification test with none let off; the settings test checks the default.
