# Start Menu Layout Visual Match, Animated Button Selection & Options Top Alignment

**Date:** 2026-10-13  
**Status:** Completed

## 1. User Request
- Match the visual menu appearance provided in the design mockup:
  - 1P card: blue background with subtle wavy checkered flag texture, white helmet silhouette on the left, bold heavy "1P" text on the right.
  - 2P card: dark/blue card, two facing white helmets (right helmet mirrored) flanking bold heavy "2P" text in the center.
  - Opciones: wide banner with golden-yellow wavy checkered background, bold white centered "OPCIONES" text (no icon).
  - Salir del juego: wide banner with red wavy checkered background, bold white centered "SALIR DEL JUEGO" text (no icon).
- Add button animation for active/selected items (subtle breathing pulse and glowing border).
- Remove the subtitle text "Carreras de motos arcade" / "Arcade motorcycle racing" below the title logo.
- Ensure the bottom legend bar has the exact same style across all views (floating pill badge bar centered at the bottom with authentic controller styling).
- In the options menu, align the modal panel to the top with a fixed `min_height` so the section selector tab bar (`[ Juego | Control | Sonido | Gráficos ]`) remains at the exact same screen height across all tabs.

## 2. Implementation Details
- **Asset Extraction & Embedding**:
  - Extracted the vector helmet silhouette from the user reference into `assets/ui/helmet.png`.
  - Added common dependency `image` with `features = ["png"]` in `Cargo.toml`.
  - Embedded `assets/ui/helmet.png` via `include_bytes!` and decoded it in `UiIcons` via `load_png_bytes`, ensuring immediate loading with zero external file load lag.
- **Procedural Wavy Checkered Flag Backgrounds**:
  - Added `draw_wavy_checker_card` generating subtle waving checkered textures for the blue card (`card_blue`), dark card (`card_dark`), golden-yellow banner (`banner_yellow`), and red banner (`banner_red`).
- **Welcome Menu Cards Layout**:
  - Rewrote the main button grid in `src/welcome.rs` with exact dimensions and hierarchy:
    - 1P & 2P cards side by side (`360x180 px`, `column_gap: 20 px`).
    - Full-width OPCIONES banner (`740x68 px`).
    - Full-width SALIR DEL JUEGO banner (`740x68 px`).
  - Removed the subtitle string from the welcome screen under the logo.
- **Button Animation System**:
  - Added `WelcomeCard { index }` component to all main menu cards.
  - Implemented `animate_welcome_cards` system oscillating scale (`1.0 + 0.016 * sin(5.0 * t)`) on the selected card while unselected cards remain steady at 1.0.
- **Options Menu Top Alignment**:
  - Changed `OptionsModal` layout to `justify_content: FlexStart` with `padding: UiRect::top(px(44))`.
  - Added `min_height: px(450)` to the inner options panel, fixing the section selector at an identical vertical coordinate across all 4 tabs regardless of row count.
- **Legend Bar Unification**:
  - Added `align_self: AlignSelf::Center` and `ZIndex(150)` in `spawn_legend_bar` in `src/ui.rs`, ensuring consistent placement in all screens.
