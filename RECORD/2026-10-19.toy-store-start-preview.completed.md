# 2026-10-19 - Toy store start preview

## Context

Follow-up to `2026-10-19.toy-store-interior.completed.md`, found while
reviewing how the finished room appears outside a race.

## User Request

Keep the toy store's interior look consistent wherever the circuit is seen.

## Implementation

- The tracks-menu look at the start (`preview.rs` / `world::build`) only
  spawns the first part of a circuit: terrain, roads, structures. For La
  Juguetería that left the camera in an empty cream void under an
  `SkyStyle::Interior` with no sky. `world::build` now spawns the room shell,
  shelves, lamps and signs for a preview as well (`room::spawn_room`), while
  a race still gets it from the toy scenery in `props.rs`.
- The conditional was folded into a let-chain, as `cargo clippy` asks.
