# Welcome Screen, Options Menu, Legend & Controller Styles Overhaul

**Date:** 2026-10-13  
**Status:** Completed  

## 1. User Request
The user requested a complete overhaul of the menu and UI screens:
1. **Start Screen (Pantalla de inicio)**:
   - Options for 1 player or 2 players side-by-side: `[ 1 player ][ 2 players ]`.
   - Represented with motorcycle helmet icons: 1 helmet for 1 player, 2 helmets for 2 players.
   - Below: Options menu `[ opciones ]` with an icon (gear) and text.
   - Below: Exit game `[ salir del juego ]` with an icon (door/exit) and text.
2. **Legend (Leyenda)**:
   - Displayed at the bottom of the screen.
   - Shows key/button badge on the left and action description on the right.
   - Styles and badges adapt dynamically based on the active controller: Keyboard, Xbox, PlayStation, or Switch Pro Controller.
3. **Options Menu (Menú de opciones)**:
   - A larger screen/modal organized by tabs: `[ Juego | Control | Sonido | Graficos ]`.
   - **Juego**: Language and steering/turn limit options previously in the Debug menu (`stick_limit`, `keyboard_limit`, `keyboard_rate`, `keyboard_return`).
   - **Control**: Control key/button bindings, plus show/hide legend toggle, reset controls, and rescan gamepads button.
   - **Sonido**: FX volume (0-100%), music volume (0-100%), and music enable/disable toggle.
   - **Gráficos**: Fullscreen toggle, resolution selector, and FPS cap selector.
4. **Pause Menu (Menú de pausa)**:
   - Displays in exact order: Continuar (Resume), Opciones (Options), Volver al menú principal (Return to main menu), and Salir del juego (Exit game).

## 2. Implementation Details

### 2.1 Procedural UI Icons & Controller Detection (`src/ui.rs`, `src/gamepads.rs`)
- In `src/ui.rs`, implemented procedural RGBA generators rendered into Bevy `Image` assets (`UiIcons` resource):
  - `helmet_1p`: 1 racing helmet with visor and glossy specular sheen.
  - `helmet_2p`: 2 racing helmets staggered diagonally (cyan and red) representing two players.
  - `draw_gear`: golden/bronze mechanical gear icon for Options.
  - `draw_exit`: red door and directional arrow symbol for Exit.
- In `src/gamepads.rs`, added `ControllerModel` enum (`Xbox`, `PlayStation`, `Switch`) with automatic name detection (`detect_controller_model`) checking vendor strings such as DualSense, DualShock, PlayStation, PS4, PS5, Sony, Switch, Nintendo, etc.
- Added `ControllerModel` to `ActiveController`, and tracked connected gamepad device names.
- In `src/ui.rs`, added `ActiveDevice` enum (`Keyboard`, `Xbox`, `PlayStation`, `Switch`) and `current_active_device(...)`.

### 2.2 Controller-Adaptive Legend Bar (`src/ui.rs`, `src/hud.rs`, `src/welcome.rs`, `src/pause.rs`)
- Created `KeyPrompt` struct and `spawn_legend_bar(...)` providing a floating pill container at `bottom: px(14)` with key badges on the left (styled specifically for Keyboard slate-rectangles, PlayStation symbols like ✕ and ○, Xbox A/B buttons, and Switch Pro A/B buttons) and action text on the right.
- Created `menu_prompts(...)` and `race_prompts(...)` returning active-device tailored button badges.
- Updated in-race legend in `src/hud.rs` (`show_race_legend`) to render at the bottom of the screen with active device badges when `show_legend` is enabled.

### 2.3 Unified Tabbed Options Menu (`src/options.rs`, `src/settings.rs`, `src/sound/`)
- Created `src/options.rs` (`OptionsPlugin`, `OptionsMenu` resource) supporting:
  - Tab navigation with `[ Q / E ]` (or `[ LB / RB ]`, `[ L1 / R1 ]`).
  - **Juego** tab: Language, stick turn limit, keyboard turn limit, keyboard turn rate, keyboard return rate.
  - **Control** tab: Interactive action rebinding with capture modal, legend visibility toggle (`show_legend`), reset controls to defaults, and rescan connected gamepads.
  - **Sonido** tab: Real-time FX volume slider/stepper (0–100%), music volume slider/stepper (0–100%), and music on/off toggle.
  - **Gráficos** tab: Fullscreen toggle, resolution selection, and target FPS limit (30, 60, 120, 144, 240, Unlimited).
- Bound sound controls in `src/sound/synth.rs` (`Controls.fx: Param`, `Mixer` real-time smoothing) and `src/sound/music.rs` (music volume scaling & mute toggle).

### 2.4 Start Screen Redesign (`src/welcome.rs`)
- Replaced old vertical text list with:
  - Top row: `[ 1 JUGADOR ]` (1 helmet icon) and `[ 2 JUGADORES ]` (2 helmets icon) side-by-side cards with highlight borders.
  - Middle: `[ OPCIONES ]` button with gear icon and text.
  - Bottom: `[ SALIR DEL JUEGO ]` button with exit door icon and text (native only).
  - Screen bottom: Dynamic controller-adaptive legend bar (`spawn_legend_bar`).
- Opening Options smoothly yields welcome screen rendering to `OptionsMenu` and restores upon return (`OptionsReturn::Welcome`).

### 2.5 Pause Menu Overhaul (`src/pause.rs`)
- Redesigned Pause menu items strictly to:
  1. Continuar (`Action::Resume`)
  2. Opciones (`Action::OpenOptions` -> opens `OptionsMenu` with `OptionsReturn::Pause`)
  3. Volver al menú principal (`Action::MainMenu`)
  4. Salir del juego (`Action::OpenQuitConfirm`, native only)
- Bottom of the pause screen renders the controller-adaptive legend bar.
